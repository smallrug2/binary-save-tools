Binary Save Decoder + Differ (sigsim_save.py)
========================================
Coded by: Muse Spark (Meta AI assistant)

License: MIT (see LICENSE file)

WHAT IT DOES:
Structurally decodes length-prefixed binary save files (string tables, scalar payloads) and diffs two saves field-by-field.

REQUIREMENTS:
Python 3.8+ only - no extra packages needed (stdlib only).

HOW TO RUN:
python sigsim_save.py --help
python sigsim_save.py parse save.dat
python sigsim_save.py diff old.dat new.dat

PLATFORM:
Windows + Linux + Mac: yes.
